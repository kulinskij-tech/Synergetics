Master’s course — draft edition, 1 October 2026.

The prerequisite notebook develops Boltzmann’s H-theorem, microscopic phase
density, the BBGKY hierarchy, correlations, the collision integral, and continuum
balance equations. Subsequent modules cover laser foundations, stability and
bifurcations, order parameters and slaving, catastrophe theory, amplitude
equations, reaction–diffusion systems, waves, synchronization, chaos, stochastic
synergetics, and networks.

## Using the notebooks

Open a notebook on GitHub to read its saved content, or use its **Open in Colab**
badge to run a personal copy. For local use, install `requirements.txt` and open
the desired notebook in JupyterLab. Mathematical derivations are Markdown cells;
computational examples are editable Python cells.
